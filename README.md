# Indian\_Road\_Safety\_Analysis\_Dashboard

Indian Road Safety Analysis

Project Overview

This project focuses on analyzing Indian road safety data to identify accident patterns, accident causes, affected regions, and road safety trends.

The main objective is to understand road accident data and generate meaningful insights using data analytics tools.

Objectives

* Analyze road accident data.
* Identify accident trends and patterns.
* Understand major causes of accidents.
* Compare accident statistics across different regions.
* Create an interactive dashboard for visualization.

Tools \& Technologies

* Excel: Data cleaning and basic analysis.
* Python: Data processing and analysis using Pandas and NumPy.
* SQL (MySQL): Data querying and analysis.
* Power BI: Interactive dashboard and data visualization.
* Statistics: Understanding trends and patterns.

Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Processing
4. SQL Analysis
5. Python Analysis
6. Power BI Dashboard Development
7. Insights and Reporting

Project Structure

* Dataset – Raw and cleaned datasets.
* Python – Python analysis scripts.
* SQL – Database and SQL queries.
* PowerBI – Dashboard files and screenshots.
* Project Report – Complete project documentation.

Key Insights

The project aims to identify:

* Accident patterns and trends.
* Road and railway accident distribution, where available in the dataset.
* Regional accident statistics.
* Major accident categories.
* Important road safety trends.

Conclusion

This project demonstrates how data analytics tools can transform raw road safety data into meaningful insights that can support better understanding of road accident patterns and road safety planning.
